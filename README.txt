PROG6112 PROGRAMMING 1B - OPEN BOOK EXAM TOOLKIT

HOW TO OPEN THIS IN NETBEANS 29
1. Extract the ZIP file.
2. Open NetBeans 29.
3. Choose File > Open Project.
4. Select the extracted PROG6112_Exam_Toolkit folder.
5. NetBeans should recognise it as a Maven project.
6. Expand Source Packages.
7. The two useful areas are:
   - arrays: Question 1 pattern
   - oop: Question 2 pattern

IMPORTANT:
The classes are deliberately written as templates. During the exam, COPY the relevant
pattern into a new class/project and change the names, variables, messages and data
to match the question.

COMMON EXAM PATTERN FOUND IN THE PROVIDED PAPERS

QUESTION 1:
- 1D String array for names/categories.
- 2D int array for two values per name.
- Scanner input.
- Nested for loops for input/output.
- Total for each row.
- Highest total using a max variable and index.
- Formatted output.

QUESTION 2:
- Interface with getter method declarations.
- Abstract class implements the interface.
- Private variables.
- Constructor.
- Getter methods.
- Subclass extends abstract class.
- Subclass constructor uses super(...).
- A report-printing method.
- RunApplication/main creates an object and calls the report method.

FAST EXAM ADAPTATION CHECKLIST

Q1:
1. Change the array name if needed.
2. Change the number of rows if needed.
3. Change the two column headings.
4. Change the prompts.
5. Change the report heading.
6. Keep the total loop unless the question asks for a different calculation.
7. Keep the highest-total logic unless the question asks for a different comparison.

Q2:
1. Rename the interface.
2. Rename the abstract class.
3. Rename the subclass.
4. Rename the variables/getters to match the question.
5. Change printReport() labels.
6. Change the sample data in main().
7. Keep super(...) in the subclass constructor.
