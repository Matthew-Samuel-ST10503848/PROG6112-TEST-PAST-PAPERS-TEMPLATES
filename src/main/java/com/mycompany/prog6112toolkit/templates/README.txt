PROG6112 PROGRAMMING 1B - EXAM TOOLKIT
VERSION 2

This toolkit is designed for an OPEN-BOOK practical programming exam.

MAIN REPEATED PATTERNS FROM THE PROVIDED PAPERS

QUESTION 1:
1. One-dimensional array for names/categories.
2. Two-dimensional array for two values per name/category.
3. User input stored in the 2D array.
4. Formatted report.
5. Total/calculation for each row.
6. Find the row with the highest total.

QUESTION 2:
1. Interface.
2. Abstract class implements the interface.
3. Private variables.
4. Constructor.
5. Getter methods.
6. Subclass extends the abstract class.
7. Subclass constructor uses super(...).
8. Report-printing method.
9. RunApplication/main creates an object and calls the report method.

IMPORTANT:
These are templates, not answers to a future exam.
Copy the relevant structure and change names, data, messages and calculations to match the actual question.

EXAM APPROACH

Q1:
- Identify what the 1D array stores.
- Identify what the 2D array stores.
- Decide how many rows/columns are needed.
- Copy the array/report structure.
- Change prompts and headings.
- Keep the total/highest logic if required.

Q2:
- Write the interface exactly as requested.
- Make the abstract class implement it.
- Add the variables and constructor.
- Add getters.
- Make the subclass extend the abstract class.
- Use super(...) in the subclass constructor.
- Add the requested report method.
- Create the object in main().
- Test the output.

COMMENTING:
The provided papers explicitly require suitable comments/good programming practice.
The comments in this toolkit are intentionally beginner-friendly so you can understand
what each line is doing and adapt it during the exam.
